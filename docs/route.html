How the route works

Stores are graph nodes. Every pair has a geographic edge weight based on coordinates. The default route is a constrained weighted-graph sweep: it preserves the requested store order and Kearny ending, while calculating every hop and total graph cost for validation. This is not DFS; DFS explores depth-first and is not a travel-minimization algorithm.

Side-trip locations such as Jersey City, West New York and Paramus remain available in stores.json but are intentionally not inserted into the default school-day sweep. They can be added later only when they improve the actual trip.
